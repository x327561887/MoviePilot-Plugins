# 批量改名（顺序重编号）

MoviePilot 插件：固定统一名称与季号，按原集数从小到大排序，从指定起始集连续递增改名。

## 效果示例

配置：标题 `Re：从零开始的异世界生活`，目标季号 `1`，起始集号 `67`，模板
`{title} - S{season}E{episode} - 第 {episode_cn} 集`。

| 原文件名 | 新文件名 |
| --- | --- |
| `Re：从零开始的异世界生活 - S04E01 - 第 01 集.mkv` | `Re：从零开始的异世界生活 - S01E67 - 第 67 集.mkv` |
| `Re：从零开始的异世界生活 - S04E02 - 第 02 集.mkv` | `Re：从零开始的异世界生活 - S01E68 - 第 68 集.mkv` |
| `Re：从零开始的异世界生活 - S04E02 - 第 02 集.srt` | `Re：从零开始的异世界生活 - S01E68 - 第 68 集.srt` |

同一原集数的视频、字幕等文件共用一个新集号；文件名中识别不到集数的文件会被跳过。

## 安装

本插件只提供 MoviePilot **V2** 版本。把 `batchrename` 目录放到 `plugins.v2/batchrename/`，
并把插件条目加入根目录 `package.v2.json`。

插件 ID 为 `BatchRename`，与目录名小写形式对应；插件版本为 `1.0.0`。
仓库地址为 `https://github.com/x327561887/MoviePilot-Plugins`，可直接作为自定义插件仓库添加到 MoviePilot。

## 使用

1. 启用插件，填写「待扫描目录」。路径是 **MoviePilot 容器内部路径**（例如已映射到容器的 `/media/动画/...`），不是宿主机路径。
2. 填写固定标题、命名模板、目标季号、起始集号、位数与扩展名；点击保存。
3. 打开插件详情页，先点「预览改名」检查清单，确认无误后再点「执行改名」。
4. 改错了可以点「恢复上次改名」回滚到改名前的文件名。

## 模板占位符

| 占位符 | 含义 |
| --- | --- |
| `{title}` | 固定标题 |
| `{season}` | 目标季号，按位数补零，如 `01` |
| `{episode}` | 新集号，按位数补零，如 `67` |
| `{episode_cn}` | 新集号（中文集数用），可单独设置位数 |
| `{old_episode}` | 原集号，便于排查 |

## 安全说明

- 只做本地文件重命名，不覆盖已存在的目标文件；冲突项会在预览清单中列出并跳过。
- 执行过程中任一步失败会自动回滚本次已改名的文件。
- 不扫描磁盘根目录；默认只处理常见视频与字幕扩展名。
- 如需处理云盘文件，请先把云盘挂载为容器内的本地目录。
