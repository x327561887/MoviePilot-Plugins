# 批量改名

MoviePilot V2 插件：预览目录里的剧集文件，勾选要改的文件批量改名。保留原标题，季号统一替换，
集号按「起始集号 → 修改集数」整体平移，「第 XX 集」自动跟随新集号。

采用 Vue 联邦模块界面，配置页与详情页完全按交互原型实现。

## 效果示例

详情页输入：目标季号 `1`，起始集号 `68`（改名起点锚点），修改集数 `100`（目标集号）。
起始集号须在目录中存在；集号小于它的标记「不匹配」不参与，其余从 100 起累加。

| 原文件名 | 状态 / 新文件名 |
| --- | --- |
| `Re：从零开始的异世界生活 - S01E67 - 第 67 集.mkv` | 不匹配（不修改） |
| `Re：从零开始的异世界生活 - S01E68 - 第 68 集.mkv` | `Re：从零开始的异世界生活 - S01E100 - 第 100 集.mkv` |
| `Re：从零开始的异世界生活 - S01E69 - 第 69 集.mkv` | `Re：从零开始的异世界生活 - S01E101 - 第 101 集.mkv` |

- 若起始集号填 `1` 但目录里是 67~77（无 E01），则全部标记「不匹配」。
- 同一原集数的视频与字幕共用同一个新集号；识别不到集数的文件会被跳过。
- 处理扩展名默认 `mp4,mkv,srt,ass`（大小写不敏感），其他文件（如 `poster.jpg`、`season.nfo`）自动忽略。

## 安装

本插件只提供 MoviePilot **V2** 版本。仓库地址：

```text
https://github.com/x327561887/MoviePilot-Plugins
```

在 MoviePilot → 设置 → 插件 → 插件市场设置（`PLUGIN_MARKET`）添加该仓库地址，
再到插件市场安装「批量改名」。

插件 ID 为 `BatchRename`，源码位于 `plugins.v2/batchrename/`。前端编译产物在
`plugins.v2/batchrename/dist/assets/`，正常安装无需重新编译。

## 使用

1. 打开插件配置，只需填写 **剧集目录**（MoviePilot 容器内部路径，默认 `/media`），
   处理扩展名默认 `mp4,mkv,srt,ass`，点击保存。
2. 打开插件详情页，填写 **目标季号 SXX**、**起始集号**（改名起点锚点，须在目录中存在）与
   **修改集数**（要改成的目标集号，如 100），点「预览改名」扫描文件。
3. 清单里每行显示「原文件名 → 修改后文件名」与状态；集号小于起始集号的文件标记
   「不匹配」且不可勾选，其余文件用行首勾选框挑选，支持表头全选。
4. 点「执行批量改名」；改错了可点「恢复上次改名」回滚。
   详情页的「⚙ 修改目录设置」按钮可直接切回插件配置页。

## 改名规则

- 保留原文件名里的标题（自动去掉 `SxxExx` 与 `第 xx 集` 片段）。
- 季号统一替换为目标季号（SXX）。
- 起始集号是改名起点锚点，目录中必须存在该集号的文件，否则全部标记「不匹配」。
- 集号小于起始集号的文件标记「不匹配」，不改名、不可勾选。
- 集号 ≥ 起始集号的文件：新集号 = 修改集数 +（原集号 − 起始集号），从修改集数起累加。
  例：起始 68、修改 100 时，E67 不匹配、E68→E100、E69→E101。
- 「第 XX 集」按新集号自动改写；E 与 S 统一按两位补零（如 `E01`、`S01`）。
- 不覆盖已存在的目标文件；冲突项会在预览清单中列出并跳过。

## 重新编译前端

```bash
cd plugins.v2/batchrename/web
npm install
npm run build
```

`vite.config.js` 使用 `@originjs/vite-plugin-federation`，把 `Config.vue` 与 `Page.vue`
暴露为 `./Config`、`./Page`，与主程序通过 `get_render_mode() -> ("vue", "dist/assets")` 对接。

## 安全说明

- 只做本地文件重命名，不覆盖已存在的目标文件。
- 执行过程中任一步失败会自动回滚本次已改名的文件。
- 不扫描磁盘根目录；默认只处理常见视频与字幕扩展名。
