# 批量改名（顺序重编号）

MoviePilot V2 插件：预览目录里的剧集文件，逐行选择要改的文件批量改名。保留原标题，季号统一替换，
集号按起始集连续递增，「第 XX 集」自动跟随新集号。

## 效果示例

配置：目标季号 `1`，起始集号 `72`。

| 原文件名 | 新文件名 |
| --- | --- |
| `Re：从零开始的异世界生活 - S04E06 - 第 6 集.mkv` | `Re：从零开始的异世界生活 - S01E72 - 第 72 集.mkv` |
| `Re：从零开始的异世界生活 - S04E07 - 第 7 集.mkv` | `Re：从零开始的异世界生活 - S01E73 - 第 73 集.mkv` |
| `Re：从零开始的异世界生活 - S04E07 - 第 7 集.srt` | `Re：从零开始的异世界生活 - S01E73 - 第 73 集.srt` |

- 季号已是目标季号的文件（如 `S01E67`）标为「已存在」，不参与改名。
- 同一原集数的视频与字幕共用同一个新集号；识别不到集数的文件会被跳过。
- 处理扩展名默认 `mp4, mkv, srt, ass`，其他文件（如 `poster.jpg`、`season.nfo`）自动忽略。

## 安装

本插件只提供 MoviePilot **V2** 版本。仓库地址：

```text
https://github.com/x327561887/MoviePilot-Plugins
```

在 MoviePilot → 设置 → 插件 → 插件市场设置（`PLUGIN_MARKET`）添加该仓库地址，
再到插件市场安装「批量改名（顺序重编号）」。

插件 ID 为 `BatchRename`，源码位于 `plugins.v2/batchrename/`。

## 使用

1. 打开插件配置，填写 **剧集目录**（MoviePilot 容器内部路径，不是宿主机路径）、
   处理扩展名（默认 `mp4, mkv, srt, ass`）、**目标季号 SXX** 与 **起始集号**，点击保存。
2. 打开插件详情页，点「预览改名」扫描文件。
3. 在清单里逐行点「选择」挑选要改的文件，或用「全选」/「清空选择」快速操作。
4. 点「执行批量改名」；改错了可点「恢复上次改名」回滚。

> 说明：MoviePilot 的详情页输入框无法把值回传后端，所以目标季号与起始集号放在配置页填写。

## 改名规则

- 保留原文件名里的标题（自动去掉 `SxxExx` 与 `第 xx 集` 片段）。
- 季号统一替换为目标季号（SXX）。
- 选中的文件按原集数从小到大排序，依次改为 `起始集号、起始集号+1、…`。
- 「第 XX 集」按新集号自动改写；新集号统一按两位补零（如 `72`）。
- 不覆盖已存在的目标文件；冲突项会在预览清单中列出并跳过。

## 安全说明

- 只做本地文件重命名，不覆盖已存在的目标文件。
- 执行过程中任一步失败会自动回滚本次已改名的文件。
- 不扫描磁盘根目录；默认只处理常见视频与字幕扩展名。
